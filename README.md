# Метод ДФП на C++

Программа `dfp.cpp` минимизирует функцию методом Дэвидона-Флетчера-Пауэлла (ДФП).

Сейчас в коде задана функция:

```text
f(x1, x2) = 4(x1 - 5)^2 + (x2 - 6)^2
```

Ее минимум находится в точке:

```text
(5, 6)
```

Минимальное значение функции равно `0`.

## Сборка и запуск

Без CMake:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic dfp.cpp -o dfp
./dfp
```

Через CMake:

```bash
cmake -S . -B build
cmake --build build
./build/dfp
```

## Что вводить

Программа запрашивает параметры по очереди.

### `n`

Размерность задачи, то есть количество переменных функции.

Для текущей функции нужно ввести:

```text
2
```

### `Initial point x0`

Начальная точка поиска минимума. Нужно ввести `n` чисел.

Например, для `n = 2`:

```text
3 4
```

Это начальная точка `(3, 4)`.

### `epsilon`

Точность остановки алгоритма.

Программа остановится, когда норма градиента станет меньше `epsilon`.

Обычно можно использовать:

```text
0.000001
```

### `max iterations`

Максимальное количество итераций.

Этот параметр нужен, чтобы программа не работала бесконечно, если минимум не будет найден достаточно быстро.

Например:

```text
100
```

### `Gradient mode`

Способ вычисления градиента:

- `1` - аналитический градиент, производные записаны вручную в `gradAnalytic()`.
- `2` - численный градиент, производные считаются приближенно конечными разностями.

Для текущей функции можно использовать оба варианта.

## Пример полного ввода

Для функции:

```text
f(x1, x2) = 4(x1 - 5)^2 + (x2 - 6)^2
```

можно ввести:

```text
2
3 4
0.000001
100
1
```

Это означает:

- функция от двух переменных;
- начальная точка `(3, 4)`;
- точность `10^-6`;
- максимум `100` итераций;
- используется аналитический градиент.

## Что выводит программа

На каждой итерации программа печатает таблицу:

```text
iter    f(x)    ||grad||    lambda    x
```

Где:

- `iter` - номер итерации;
- `f(x)` - значение функции в текущей точке;
- `||grad||` - норма градиента;
- `lambda` - найденный шаг вдоль направления спуска;
- `x` - текущая точка.

В конце выводится:

```text
x*
f(x*)
||grad(x*)||
iterations
```

Это найденная точка минимума, значение функции в ней, норма градиента и количество выполненных итераций.

## Пример результата

Для ввода:

```text
2
3 4
0.000001
100
1
```

программа должна прийти к точке, близкой к:

```text
x* = (5, 6)
f(x*) = 0
```
